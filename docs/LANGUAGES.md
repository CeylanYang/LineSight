# 中文和 English

使用 **1.1.10 或更新版本**。登录后点击底部 **我的 → 语言 / Language**，
在弹出的列表中选择 **English** 或 **中文**。整个设置行都可以点击，
当前位置在个人资料卡片下方。切换成功后会立即更新界面，并保存到本机。
英文界面的对应入口为 **Profile → 语言 / Language**。

首次打开默认为中文。登录页右上方也可以选择语言，无需先创建账户。
语言选择是本机设置，所有本机账户共享。重新打开应用后保留选择；
每次冷启动仍需登录。语言设置不会改变用户名、姓名、配方名称、备注、
历史日志原文或原始检测结果。复核页面内的草稿在切换语言时保留。

标准日期选择器、确认按钮及返回按钮使用当前语言。内置缺陷类别支持英文
显示和英文搜索；例如 `surface scratch` 可找到存储为“表面划痕”的记录。
CSV 表头使用打开导出预览时的语言，列顺序和原始业务值保持一致。

语言目录由 `tool/l10n_source.json` 和 `tool/en_translations.txt` 管理。
执行 `python tool/build_l10n.py` 生成 `lib/l10n_catalog.dart`，生成器会
检查条目和插值参数是否完整。新增页面应使用 `tr(context, source, args)`。
服务错误和进度消息在展示边界使用 `trMessage`，用户自由文本直接显示。
一次性迁移及审计脚本以 `.dart.txt` 归档，运行时使用 Flutter 工具的
package config；它们不是应用依赖。
