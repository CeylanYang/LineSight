# LineSight 1.1.56 界面与导航调整

本轮按用户指定的“入口集中、分区明确、信息丰富”重组现有业务。使用现有 Flutter 组件实现，参考国内常用 App 的顶部工具区、功能宫格、分类列表和持续可见的主操作。本地未发现 Open Design Motion 包，没有声称使用该插件。

## 已调整

- 未登录的工作台直接展示“登录工作区”、登录、刷卡登录、进入演示团队。删除原先两个重复登录按钮及登录中转页；会话过期等必要认证继续复用同一登录组件。
- 工作台顶部四项常用操作：在线质检、扫码追溯、新建任务、质量报告；后接八项紧凑入口：待检、异常、记录、打印配置、检查模板、团队、卡片、同步草稿。只读成员使用生产查询替代新建任务。
- 三项质检概况合为横向摘要，保留原统计口径及带条件跳转；首页移除生产任务长列表、七天趋势和折叠分类待办，只保留最多两项个人待办。
- 五项主导航为工作台、生产、质检、配置、我的。生产直接显示任务列表；质检页内分为待检、记录、报告；配置页内分为打印配置与检查模板，分类下直接显示内容。
- 工作区切换和通知置于顶部；卡片管理在工作台和“我的”中直接可见；本机配置工具移至“我的”。
- 任务详情移除优先展示的装饰大图，固定主要处理按钮；单个未处理异常直接打开处理表单。新建任务、检验/异常提交和使用配置/模板创建任务的主操作固定在底部，键盘弹出时保留操作区。
- 报告筛选、CSV、预览及系统 PDF 入口置于顶部，并沿用当前查询条件。
- 同级切换保留页面状态，详情及表单返回保留来源；工作区切换、无权限及会话过期沿用现有鉴权。加载失败与空数据分别显示。
- 返回规则、开发解释和验收说明留在内部文档。移除本轮涉及页面中的返回逻辑说明及提交后的实现性说明，界面保留操作名称、字段提示和必要的业务状态。
