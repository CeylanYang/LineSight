# 1.1.46 配方配置与任务衔接

本轮新增配方中心二级导航、云端打印配置列表和详情、配置选择回填、配置草稿恢复、模板详情按所选历史版本创建任务、任务配置版本与来源展示，以及本机配方/换型/系统的授权入口。

## 操作路径

- 配方中心 → 打印配置 → 配置详情 → 使用此配置创建任务。
- 新建任务 → 选择打印配置 → 配置详情 → 使用此配置 → 返回原表单；返回取消保留原设备。
- 已选配置右侧关闭按钮切换为手动设备，其他字段保留。
- 配方中心 → 检查模板 → 模板详情 → 使用此模板创建任务，固定所选模板版本。
- 配方中心 → 本机配方与工位 → 本机授权 → 原有配方/换型/系统。深层页面在本机锁定后整体关闭。

## 验证与素材

PNG 是 Flutter 组件测试生成的 360×1100 中英文画面，不是最终 APK 原生截图。截图使用固定 UI 测试配置，不代表实际云端探针数据。旧模板详情与统一登录图片同步当前按钮和版本号。

实际 HTTPS 在新建的隔离探针工作区中验证配置读取、创建任务、请求重放、旧任务快照不变、新任务使用新配置，以及无效配置拒绝；临时 Keycloak 身份和会话已清理。仅创建该探针的两条任务，不修改既有用户数据。

本轮没有修改云端代码和数据库结构。打印配置编辑/复制、工位关联仍待后续完善；总表、真实手机相机/NFC、多设备与外部用户验收尚未全部完成。最终 APK 原生逐屏验证未完成，模拟器此前持续发生宿主进程崩溃。本机应用与设备数据未清除。
