# 1.1.50 同步诊断与使用说明

“我的 → 同步与草稿 → 同步诊断”按故障提供恢复操作：登录失效进入统一二级登录，权限不足刷新团队权限，服务故障或断网允许重试读取。返回登录页后可以回到诊断，诊断检查不执行业务写入。本机草稿读取失败仍检查云端连接，无法读取的数量显示“—”。

切换账户、团队或角色后立即清除旧诊断；旧请求返回不会覆盖当前团队，也不会在迟到的本机读取后继续请求旧团队。复制诊断仅包含版本、平台、检查时间、工作区编号、数量和状态码，不包含原始错误、草稿正文、账户凭证或令牌。

“我的”增加“使用说明与应用信息”，介绍当前任务、检验、异常复检、报告、云端登录与本机数据流程。旧版“应用没有云账户和同步服务”已移除。本机工位按钮改为“添加示例记录”，生成中也明确显示示例。

新增 11 项交互测试及 6 张中英文组件 PNG，图片使用固定时间和测试数据，属于 Flutter 组件渲染。本批后端未修改，沿用上一批 87 项后端测试和真实云端交接证据。最终 8074 APK 尚未完成原生导航验证；上一批模拟器升级和启动成功，但后续模拟器进程退出，原因未确认。用户当前无真机，物理相机、扫码、NFC、触觉与双真机验收继续保留。
