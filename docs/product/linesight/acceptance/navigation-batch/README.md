# LineSight 1.1.39+8063

本批修正二级页面的返回落点，并完善追溯链接失败后的恢复操作。

- 普通二级页面返回时保留来源标签及其状态。
- 在检测记录、配方中心或我的主标签按Android返回键，先回到工作台。
- 点击“返回工作台”同时切换到工作台标签并关闭上层页面。
- 追溯链接保留401/403/404等错误状态，分别提供登录、刷新权限、返回工作台等操作。未知原始错误不显示在客户页面。
- 页脚版本与安装版本同步，构建时校验两者一致。

240项Flutter测试通过，静态分析无问题。其中20项新增测试覆盖三个主标签的系统返回、普通二级页返回，以及三个来源标签下六类恢复入口清理嵌套路由。原有追溯越权测试同步验证返回工作台，无任务内容泄露。后端未改，本批未重新运行后端测试。
