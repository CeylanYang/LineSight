# 云端密码与会话验证

使用一次性普通测试身份执行官方Keycloak原生客户端PKCE登录，创建两个独立会话。通过Keycloak账户密码更新页修改该测试身份的密码，并选中官方退出其他会话选项。旧密码被拒绝，原访问及刷新令牌失效；新密码可重新PKCE登录。

官方账户会话接口的单会话撤销、保留当前并撤销其他会话、当前退出均实际验证。独立演示身份不能撤销该普通测试身份的会话。未开启普通原生客户端的密码授权，未修改已有用户或演示账户密码。

证据为Python urllib发起的真实HTTPS请求，非物理Android设备。公共夹具不包含访问令牌、刷新令牌、具体会话ID或IP。测试结束已删除Keycloak临时身份并退出测试登录；后端可能保留隔离的验收身份及工作区记录。SMTP尚未配置，邮件找回不能据此标记完成。App会话管理界面仍需开发。
