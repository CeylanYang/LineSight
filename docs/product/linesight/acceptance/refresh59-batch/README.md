# 8078 会话恢复补丁验收

在最终 APK 验收中，启动恢复失败后出现通用错误，账户信息未载入。截图 328 为现有普通预览 APK 的真实模拟器界面；它只证明可见症状，不能单凭截图判断服务端错误类别。

源码核查发现 flutter_appauth 12.1.0 的 FlutterAppAuthPlatformException.details 是兼容旧版本的动态字段，可能是字符串、Map 或空值；有类型的 OAuth 错误位于 platformErrorDetails.error。旧代码读取 details.error，会在处理刷新失败时再次抛出异常。

补丁改为官方字段及 invalidGrant 常量。新增 6 个回归，覆盖三种旧字段类型，分别验证：

- invalid_grant 清除当前登录凭据及缓存视图，转为需要重新登录。
- 网络故障保留会话，提示恢复失败，不输出平台错误正文。

459 项 Flutter 回归及静态检查通过。测试源码为 test/cloud_appauth_refresh_test.dart，构建使用既有 8078 基线、内容版本 2。补丁发布和原生验证结果以同目录最终 JSON 为准，不能把构建通过视为全部原生页面验收完成。

预览序号 4、正式序号 1 均已发布 arm64-v8a/x86_64 补丁。四份清单通过 Ed25519 验签，补丁 SHA256、大小、ABI 及 APK 中的实际 AOT 字节一致；与冻结基础 APK 相比，除 libapp.so 外的原生及资源指纹不变。两种 APK 签名校验通过，最新交付在 `D:/ENT207/deliverables/LineSight-1.1.54-content2/`。

真实模拟器依次显示“更新已准备好”、冷启动加载 ota-4、“登录已过期，请重新登录”，点击后进入二级登录页。安装版本仍为 8078，lastUpdateTime 保持 2026-10-24 05:44:43，没有重新安装。328–330 有 PNG 与 UI XML；331 PNG 已视觉核对为二级登录页，但抓取 XML 时模拟器进程退出，因此没有对应 XML。后续演示登录未执行，不能计为登录成功或全页面验收。
