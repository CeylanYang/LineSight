# 1.1.49 任务负责人和异常交接

从任务详情右上角“更改负责人”进入二级表单，选择当前团队的可操作成员，或退回未分配队列。保存成功回到任务详情并立即显示服务器回执。未保存返回会确认放弃；提交中避免重复操作。

异常任务交接必须填写说明，所有未完成异常随任务交给新负责人；原检验记录和已解决异常保持原样。接手人收到通知，改派后旧接收人的通知移除。历史中可查看交接前后负责人、说明和操作人。

遇到他人同时修改时，展示最新任务供核对；选择按最新任务继续后，再手动保存。网络重试复用同一请求键，防止重复执行。只读成员没有改派入口，跨团队负责人及已关闭任务由服务器拒绝。
