# 1.1.30 云端反馈与恢复

生产任务列表、任务详情、检测记录、质量报告与图片证据页接入统一恢复提示。断网可重试；401进入统一登录二级页面；403先刷新权限；404可返回工作台；409只刷新读取状态，由用户核对后再次提交。任何恢复按钮都不重放写入命令。

列表失败时不显示空数据提示，重试保留筛选范围。报告指标尚未加载或加载失败时隐藏统计及导出区，避免呈现虚假的0。加载过程使用静态骨架和屏阅读提示，不增加大型动效。任务详情绑定原账户、团队和角色，切换后旧页面不可继续操作。

只向客户展示已收录的业务提示或按状态选择的中英文恢复文案，原始异常、HTML及未知服务端内容不直接进入这些页面。HTTP空JSON错误不再导致解析异常，403/502等状态保留给恢复界面。

## 验证

本批9项客户端测试覆盖筛选保留、403权限刷新、401统一登录、409只读恢复、加载/空态区分、记录及图片错误、双语360宽渲染，以及本机HTTP服务器实际返回空JSON 403/HTML 502时的状态保留。输入为受控错误夹具，不是对生产服务制造故障。

4张PNG均为Flutter桌面组件测试渲染，使用已加载的中文字体与模拟错误。状态集合图展示加载与6类恢复提示；任务图展示BATCH-007待质检筛选在断网时的恢复入口。它们不是Android截图，也不构成实机网络故障验收。

全量客户端测试、静态分析、构建、签名及安装包检查结果见 `validation.json`。本批未修改后端；后端38项为上批已验证基线。未启动虚拟机/模拟器/QEMU，未安装卸载或清除数据。Android实机、升级、物理相机、双真机与外部用户验收继续。
