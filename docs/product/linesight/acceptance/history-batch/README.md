# 1.1.29 任务历史与逐件检验

任务详情采用可展开时间线，显示操作者、真实时间、状态变化、任务版本、对象编号、检验轮次和数量。照片事件保留阶段，异常处置说明完整展示。历史稀疏事件通过不可变检验记录补充展示，不回写原事件，不推测缺失的状态变化或操作者。

检验详情新增逐件SN判定。切换账号、团队或角色后原记录隐藏，避免跨工作区展示。

## 云端验证

仅在独立演示团队5创建两件SN的演示任务，真实HTTPS完成打印、首检、整改、复检并关闭。首检1合格/1异常，复检2合格，稳定请求键重试未增加记录或事件。8条事件保留操作者、对象、工作区、任务及版本来源，匿名访问401，外部工作区404。

`live-api.json` 为结果，`live-history.json` 为云端只读记录夹具。上传图片是生成的32×32演示PNG，未使用物理相机。测试令牌在脚本结束时退出。后端上线前保留28张原表及全部原行；无需数据库迁移。
