# LineSight 1.1.54：自托管 OTA

已接入开源 MIT 模块 [flutter_patcher 0.1.4](https://github.com/xuelinger2333/flutter_patcher)，并在现有服务器部署只读补丁分发接口。

首次请使用与原安装版本签名一致的 1.1.54 APK 覆盖升级。此前使用预览包的设备继续安装 preview 包；production 包使用独立正式签名。
无需卸载或清空数据。以后 Dart 页面、路由和业务逻辑更新可在启动后自动下载，下次冷启动生效。
入口：“我的 → 应用更新”；本机工作区的设置中也可查看。

补丁经过 Ed25519 验签、SHA-256、版本/ABI/通道检查；发布工具拒绝原生代码、引擎、权限和资源变化。
原生插件、权限或打包资源更新仍需发布新 APK。

验收通过：453 项 Flutter 测试、97 项后端测试、静态检查。
Android API 34 x86_64 模拟器使用原有账户覆盖升级，完成内容版本 0 → 1 → 0 → 1 的下载、生效、签名回退和自动恢复流程。
整个补丁流程 APK 安装时间保持不变，lsuser01/checkcheck 会话保留。
6 张原生截图及 XML、加载器日志、签名元数据和校验记录保存在本目录。

正式通道保持无测试补丁。正式包完成编译与签名验证；原生运行流程使用预览签名包验证。
自动启动崩溃回退已沿用模块实现，本轮没有注入崩溃补丁。尚无物理手机覆盖测试。

开发发布与回退命令见 [OTA.md](../../OTA.md)。
