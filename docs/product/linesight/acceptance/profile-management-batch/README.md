# 1.1.47 配置维护与模板关联

本轮新增团队打印配置创建、编辑、复制及默认检查模板绑定。内置配置通过复制创建团队配置；团队所有者维护，操作员选用，查看者只读。默认模板固定到具体版本，创建任务仍可改选；已建任务及历史检验不随后续配置修改而改变。

## 操作路径

- 配方中心 → 打印配置 → 右上角加号 → 创建打印配置。
- 配置详情 → 编辑打印配置 → 保存 → 完成，返回更新后的同一配置。
- 配置详情 → 复制打印配置 → 修改名称并保存，返回新配置详情，原配置保留。
- 配置默认检查模板 → 模板详情，可检查所绑定版本和检查项。
- 配置详情 → 使用此配置创建任务，设备与默认检查模板回填；保存草稿会保留所选配置。失效修订提交被拒，保留表单供重新选择。
- 本机配方与工位 → 配方详情 → 应用配方 → 工位换型。此项沿用已有本机授权和换型实现，本轮新增中英文截图；不将云端配置自动写入本机工位。

## 保存与冲突

同一内容重试复用请求键；不同内容或账号复用被拒绝。收到成功回执后立即更新父页面和配置列表，不依赖二次 GET；延迟的旧列表响应不会擦掉已确认的新配置。

旧修订不能覆盖新配置；页面展示当前版本，用户可明确选择基于最新修订保留编辑内容，并再次手动保存。返回时询问是否放弃未保存修改。切换团队或账户后隐藏编辑内容并忽略迟到的保存结果。

## 验证和素材

本轮 14 张 360×1100 中英文 PNG 是 Flutter 组件渲染，采用固定测试数据与证据字体，不是最终 APK 原生截图。包括创建、编辑、复制、详情、成功回执、冲突及本机工位换型。

真实 HTTPS 使用临时 Keycloak 用户的新建隔离工作区，验证两位并发编辑请求一个成功一个冲突、默认模板与历史任务快照、保存回执重放和复制。产生两条探针任务和两份探针配置；临时身份与会话已清理，探针后端记录留存。既有用户数据未改写。

云端新增迁移 0009 的两个字段，停止服务后备份数据库和代码；迁移后核对 31 张表的全部既有行，原有配置修订初始化为 1，默认模板为空，健康检查通过。详见 deployment.json。部署工具带旧文件哈希和迁移前置校验，不能重复部署覆盖后续改动。
