# 1.1.32 NFC卡片登录

统一登录二级页面增加刷卡登录；账户与安全中增加我的卡片，可绑定与解除绑定。绑定时可选择初始化空白NDEF卡。读卡扫描在离开页面或应用后台时停止；本机绑定记录和设备密钥使用独立加密安全存储，不清除旧会话或用户数据。

服务端接入Keycloak官方Authenticator SPI，使用服务端一次性断言换取由Keycloak签发的访问及刷新令牌。刷卡与密码登录使用相同身份／团队体系。NFC刷新必须完成设备签名挑战，轮换旧刷新摘要；解绑即时拒绝NFC业务访问和刷新。普通账户继续使用PKCE。详细认证设计、卡型范围和部署方式见 `deploy/nfc/README.md`。

## 验证来源

`live-api.json` 来自实际HTTPS验证：一次性普通测试身份通过PKCE登录并绑定生成的卡片摘要及Ed25519设备密钥，完成NFC登录、轮换刷新、单会话退出、解绑撤权；证明复制卡号但没有设备私钥不能登录，密码会话不受影响。测试后删除临时Keycloak身份，业务库仍可能保留隔离的验收记录。

八张中英文PNG是Flutter桌面组件渲染。卡片列表使用云端响应对应的公开夹具，账户和绑定ID已脱敏，卡片标签为LineSight · 01；绑定图是开始读卡前的界面，另含新的账户入口和统一登录页。它们不是Android截图，也不代表已使用实体卡。

未启动虚拟机、模拟器或QEMU；未自动安装、卸载或清除手机数据。真实手机NFC读取、卡型兼容、物理相机和覆盖升级验收继续。完整产品计划仍未全部完成。
