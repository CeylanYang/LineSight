# 1.1.48 创建任务后的详情与返回路径

创建任务收到服务器成功回执后，直接进入新任务详情。新详情替换创建表单，返回到发起创建的工作台、列表、配置详情或模板详情；不会重新进入已提交表单。原工作区列表在后台刷新，刷新等待不阻塞已确认结果。详情读取失败时保留服务器创建回执中的任务信息，刷新仅重试读取。

创建请求失败时仍留在表单并保留草稿。请求期间切换团队、账户或离开表单，迟到回执不导航、不刷新新团队、不删除原草稿。草稿清理失败不将服务器成功改成失败；原草稿的请求键保留，后续同内容提交由现有服务器幂等回执返回同一任务。
