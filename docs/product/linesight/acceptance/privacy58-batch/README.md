# 故障日志脱敏验收

2026-10-24，App 基线保持 1.1.54+8078，本批只修改服务端日志，不需要更新 APK。

- Django 日志使用字段白名单：时间、级别、来源模块及行号、异常类型及函数位置、状态码、请求方法、URLconf 路由模板、服务端生成的请求编号和耗时。不格式化原始消息、参数、异常值、异常链文本、请求头、查询、正文及任意附加字段。
- HTTP 401/403/409/413/5xx 分别记录认证、权限、写入冲突、文件过大、服务错误，错误可按请求编号关联。业务参数和工作区/成员/工件的实际路径值不进入日志。
- 新增 4 项回归，包括真实 Django 异常链和包含密码、访问/刷新令牌、邀请码、Cookie 的请求。全部 101 项后端测试通过，见 backend-tests.txt。
- 已部署生产，Django check、服务健康、无效认证 401、未知路由 404 通过。3 个线上探针的敏感标记未进入 journal，请求编号能关联。见 live-logs.json。
- Caddy 2.11.7 使用现成 filter encoder 移除请求、头、URL、原始消息及错误字符串。保留级别、logger、时间、状态、耗时及错误定位字段。隔离代理连接不可达上游返回 502，含敏感标记的 URL/query/Authorization/Cookie 未进入日志；测试进程已退出。生产 API 和官网 HTTPS 仍为 200。见 proxy-logs.json。
- Gunicorn 生产单元未启用 access logfile；本次未开启 Keycloak HTTP access log、SMTP 调试或邮件正文日志。Postfix 默认投递日志包含发件/收件邮箱及投递状态，不包含邮件正文或 SMTP 授权码，访问限于服务器运维。邮件重置动作链接不纳入交付。
- Dart 源码显式输出仅有 lib/startup_trace.dart；发布默认关闭，只输出启动事件、阶段、布尔状态及耗时。已有 test/diagnostics_recovery_test.dart 验证诊断复制字段白名单、原始响应隐藏和跨身份迟到结果隔离；本批未改动客户端，沿用既有证据。
