# LineSight 1.1.36+8060

本批交付任务更新冲突的版本对比、检查模板变化后的重新核对、序列号同步，以及整块账户卡片进入二级账户页。

## 安装包

- `LineSight-1.1.36-8060-preview.apk`：沿用已有预览签名，可覆盖同签名旧版。
- `LineSight-1.1.36-8060-production.apk`：正式签名，供同正式签名的安装链使用。现有预览签名不能直接覆盖为正式签名。
- 两包均支持 ARM64 与 x86_64，非调试构建，不包含验收插件或存储检查工具。签名私钥未随包交付。

## 本批操作

1. 填写任务检验。另一端更新任务后提交，显示编辑时与更新后的版本、状态、轮次及变化字段。
2. 点击“查看最新任务”打开最新详情，返回后保留原草稿。
3. 可继续检验的任务，显式确认后采用最新版本。检查模板变化时重新逐项核对，序列号按最新任务同步。
4. 已关闭任务不再提供继续检验入口。点击“返回并刷新任务”回到最新父页面。
5. 在“我的”点击账户姓名、头像或卡片区域，进入账户与安全。返回仍停留在“我的”。

## 验证记录

- 199 项 Flutter 测试通过，静态分析无问题。后端代码未改，本批未重跑既有 57 项后端测试。
- 原模拟器从 8059 覆盖为 8060，12 个持久化文件、1 个数据库、密钥别名及校验标记安装前后相同。最终重打包再覆盖安装也通过相同检查。
- 普通 Android release APK 操作独立演示团队中的本批任务。另一客户端先完成检验，Android 旧表单收到 409。界面显示版本 3→4、待质检→已关闭、轮次 0→1。
- 查看最新详情后返回，`Bracket dimensions checked` 备注保留。云端复核仅一条检验，结果未被旧表单覆盖。
- 点击账户姓名区域进入二级页，再返回保留“我的”。本批未执行物理 NFC 刷卡。
- 发现旧演示会话恢复显示通用失败，演示刷新改用标准令牌接口。最终 APK 能将失效会话转到登录，重新进入演示团队后完成上述流程。令牌轮换、沿用与撤销分支另有 3 项 HTTP 测试。未将这些测试计为真机成功刷新证明。
- 没有卸载主 App、清空 App 数据或向手机安装。模拟器分辨率恢复为原覆盖 1080×1920，密度恢复 420，完成后关闭。
