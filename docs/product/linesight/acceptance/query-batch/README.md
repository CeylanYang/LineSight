# 统一筛选与报告批次

源码版本 1.1.24，普通入口构建号 8036。全部操作使用独立云端演示团队。

- 任务列表支持任务号、批次、名称、状态、负责人、未指派、任务日期、异常类别组合筛选，包含加载、空态、刷新和范围报告入口。
- 检验记录支持检验人、结论及相同任务范围筛选；记录保留实际检验时间、轮次和快照。当前日期选择明确作用于任务创建时间；独立检验时间段筛选仍在后续清单。

- 报告预览含团队、云端来源、筛选范围、追溯编号、批次、人员、轮次、模板版本、异常处置和证据缩略图。PDF 含相同来源和证据；CSV 增加范围与轮次数量明细。
