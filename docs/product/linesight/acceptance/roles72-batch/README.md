# 四角色配置、模板、团队导航补验

组件层新增 8 组 360×800 测试：中英文 × 管理员、主管、操作、只读成员。加载仓库内 NotoSansSC 字体，实际进入配方中心 → 打印配置 → 详情及检查模板 → 详情；验证管理入口和任务入口权限，允许操作的角色进入任务表单后用系统返回恢复原详情，再逐级返回入口。团队页检查邀请和成员菜单仅对管理员显示。全过程没有提交写入请求。8 组通过，该测试文件静态检查无问题。

首次运行测试夹具使用了未加载字体及工具栏返回，导致字形宽度和无工具栏路由返回断言失败；改为加载真实字体、调用系统返回后通过。未修改 App 产品代码，未发布 APK 或 OTA。

原生部分尝试在保留安装和数据的 `LineSightProductionFreshValidation` AVD 继续验收：单台，申请 1536MB/2 核、软件 GPU、隐藏窗口、独立标准输出及错误日志。启动后观察到 boot_completed=1，App 显示前一临时身份过期状态；进入登录前，宿主 emulator 和 qemu 进程均消失，adb 无设备。未获得明确退出原因，因此不声称 GPU、启动方式或 App 已修复。没有卸载、清数据或重置 AVD。

四个本批临时 Keycloak 身份、四个 API 用户及五个临时工作区已按前缀和成员关系校验后删除，私有状态已清理，客户团队未修改。记录时无连接的模拟器，也无仍运行的 emulator/qemu 进程。

原生角色路径、原生即时撤权、邮箱往返及硬件验收仍待完成。组件测试不能代替原生验收。账号/页面工具支持独立批次和截图编号，以免后续运行覆盖历史证据。
