# LineSight 1.1.38+8062

本批完善新建任务、检验/异常处理和检查模板发布的表单操作。

- 点击提交时，定位第一个需要修改的字段或检查项，提示显示在对应位置。
- 新建任务校验SN数量、唯一性及单号长度；负责人可改回未指派。模板、负责人和SN模式变化后立即保存草稿。
- 检验在本机核对必填检查项、不合格问题说明、SN结论、非负数量、计划上限和结论数量一致性。异常处置关闭须填写授权依据。
- 模板发布先核对名称、3至6项和单项120字符限制；发布期间锁定输入，跨工作区旧回调仍被拦截。
- 补齐分组标题和校验提示的中英翻译。后端权限、数量和状态校验继续生效。

220项Flutter测试通过，静态分析无问题。新增9项测试覆盖小屏错误定位、无效输入不写入、草稿保留、取消指派和中英文渲染。后端未改，本批未重跑既有57项后端测试。

本批使用普通Android release APK，覆盖原8061安装为8062，不卸载、不清空数据、不向手机安装。存储JSON记录升级前后持久化内容；普通APK操作截图以`-emulator.png`结尾。`114`及`115`为Flutter组件渲染。历史PNG保留；统一登录PNG另留本批版本号，避免改写旧材料。

升级前基线沿用上一批关闭模拟器前采集的`reauth-batch/final-runtime-storage.json`，本批`before-upgrade-storage.json`为其逐字节副本。开机时首次存储检查超时，随后覆盖安装完成。安装后的新检查与该基线的12个持久化文件、1个数据库、密钥别名和校验标记均一致；未将超时检查记为成功。

原生表单验证使用独立演示团队中的新任务，不提交无效检验。`live-forms.json`由HTTPS查询记录检验前后版本和轮次，确认未生成检验；也记录本轮模板数量未变。演示账号无模板发布权限，原生仅验证并截图模板详情；模板发布的缺项和长度限制由组件测试验证，管理员原生发布验收仍待完成。`native-journey.json`记录界面观察与截图哈希，完整验证结果见`validation.json`。

提供预览签名和正式签名两份APK，均支持ARM64与x86_64。预览签名只能覆盖同签名旧包。正式包使用既有正式签名，本批不将预览覆盖安装声称为正式升级验收。

模拟器验收后恢复1080×1920覆盖分辨率及420密度并关闭。实体卡、手机摄像头/触觉、双真机和10名外部用户仍待验收；完整产品计划继续推进。
