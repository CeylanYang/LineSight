# 特供版生活圈（1.1.61 / 8085）

本轮冻结大字版的信息架构和业务流程。设置开关仍为关闭=大字版，开启=特供版。

## 交互范围

- 首页保留在线质检、扫码追溯、新建任务、质量报告等原有工作入口。在会员横幅下增加生活圈宫格；二级页面右上角可进入全部服务。
- 14 个入口：金融、视频、股票、短剧、金币、阅读、积分、碎片、跑步、健康、运动、保险、租车、会员。
- 福利中心增加可关闭的金融推广弹窗；仅进入福利中心后触发，不侵入普通版或登录恢复流程。
- 宫格与会员卡采用有限时长的弹跳/晃动/缩放；遵从减少动态效果设置，没有持续循环。
- 会员四级均免费领取：铂金、钻石、至尊、无上。个人头像下显示 SVG 等级标识；只升级不降级。会员不修改真实团队角色或业务权限。

## 可操作功能

| 页面 | 行为 |
|---|---|
| 视频、短剧 | 本地样例 MP4，播放、暂停、拖动、上一集/下一集、选集、收藏、继续收藏剧集、观看后领取每日积分 |
| 阅读 | 三章原创生活短篇、章节切换、字号、书签、恢复章节 |
| 金融 | 金额/期数选择、等额本息试算、方案收藏 |
| 股票 | fl_chart 固定样例图表、金额校验、收益计算、阶段表格、内嵌自托管 WhatIfIBought |
| 金币/积分 | 签到、好礼、免费宝箱、任务入口、积分兑换、领取/兑换明细、每日去重、不允许负余额 |
| 碎片 | 六块碎片点亮并保存，集齐领取奖励 |
| 跑步/运动 | 开始、暂停、继续、结束保存、最近记录；后台暂停，不伪造定位或步数 |
| 健康 | 当日喝水计数、撤销、目标进度、跨日重置 |
| 保险 | 三种样例方案比较与收藏 |
| 租车 | 城市/车型/取还日期、费用估算、日期约束、行程计划保存 |

新增会员、书签、碎片、运动、健康与方案采用账号命名空间保存在本机偏好中，并沿用串行事务队列。它们目前不进行云端同步；原有积分系统沿用设备福利账本。
金融、保险和租车为可交互的样例试算/方案，不接入交易、扣款或实际预订。
