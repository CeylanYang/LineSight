## 运行方式

- `linesight-dispatch.timer`：北京时间 09:00、12:00、18:00，Persistent=true。
- `linesight-dispatch.service`：systemd oneshot，按时启动，完成后退出；没有闲置常驻 Python 进程。
- 资源限制：192 MB 内存、25% CPU、Nice=10、120 秒超时。
- `flock` 防止任务重叠；数据库事务、工作区写锁和唯一 source_key 防止重复。
- 服务启动会补发当天已经到点但尚未生成的时间段；不会无限回填历史日期。
- 通知接口最多返回最近 120 条已发布的工作区预告。任务和模板保留为业务记录。

运维：

```sh
systemctl list-timers linesight-dispatch.timer
systemctl status linesight-dispatch.service
journalctl -u linesight-dispatch.service
systemctl start linesight-dispatch.service
systemctl disable --now linesight-dispatch.timer
```

关闭整个定时器可停止后续生成。也可将某个工作区 `dispatch_enabled` 改为 false，仅停该团队。

实现入口：`backend/collaboration/dispatch.py`、`management/commands/dispatch_workspace.py`、迁移 0011；部署单元位于 `deploy/linesight-dispatch.*`。

上线前已备份源码和 SQLite 一致性快照，位置见交付包 deployment.json。服务、官网和认证保持现有配置。
