# LineSight 1.1.57 检查模板交互

本轮重点是模板的展示和可操作性。沿用已有云端模板、角色权限、版本和检验快照，使用 Flutter 组件接入现有页面。

## 完成内容

- 模板目录支持按名称及检查项搜索，按全部、团队模板、内置模板筛选；卡片直接显示检查内容、版本、来源和数量。
- 卡片提供“交互预览”和“用于任务”。后者直接进入新建任务并选中对应模板；返回目录保留搜索和筛选。
- 模板详情直接进入交互预览。点击检查项展开，选择合格、异常或模板允许的不适用；异常可填写问题说明。
- 进度环、已检查数量、合格/异常/待检查计数随操作更新，完成后显示预览完成；支持下一项、返回首项和重置。
- 切换模板版本重新开始预览；创建任务使用明确选择的模板版本。预览答案和说明保存在独立页面状态，不写入检验记录、不改动模板、不带入正式任务。
- 编辑器顶部可预览当前填写内容，返回继续编辑；发布按钮固定底部。模板版本冲突、幂等发布、复制与历史快照机制沿用既有实现。
- 只读成员可以体验模板；创建任务和发布管理操作仍按现有角色权限显示。切换工作区或退出后隐藏原工作区的预览。
- 首屏移除模板归档机制等开发解释，保留简短操作名称；窄屏、大字号下按钮自动纵向排列，中英文界面可用。

本轮仍使用既有合格、异常、不适用检查项，数值公差自动判定、AQL 抽样及量具管理不在本次开发范围。

## 验证

新增八项交互测试，覆盖预览不产生云写入、异常说明和重置、版本切换、精确模板选用、目录返回、搜索恢复、只读权限、工作区隔离、编辑预览及中英文大字布局。**495 项 Flutter 回归测试全部通过，静态检查无问题**；日志与安装包哈希见交付目录 `delivery.json` 及本批验证文件。
