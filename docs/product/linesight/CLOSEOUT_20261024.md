# LineSight 当前版本开发收尾

按用户最新要求，本轮以可用软件、签名安装包、已有自动测试及模拟器证据收尾，关闭当前开发目标；未进行的真机、外部用户与运维演练另列后续工作，不作为已通过验收。

本轮验收安装包：**1.1.55+8079，内容版本 5**。官网 https://99ai.pronhubcn.com/ 继续提供已发布的 **1.1.54+8078**。新包中的原生日志变更需要安装 APK，不能通过旧基础版本的 Dart OTA 下发。

| 配置与模板 | 打印配置及检查模板列表/详情/创建/编辑/复制，版本快照，带配置新建任务，角色权限控制 |

NFC 已接入常见卡型读取路径，不表示任意卡片均可写入或已逐型号测试。OTA 当前覆盖 Dart 页面、路由及业务逻辑；权限、原生插件、引擎、打包资源等变更仍需新 APK。

## 本轮验证依据

- 474 项 Flutter 测试通过；最近服务端回归为 101 项通过。
- 两种签名的 8078→8079 覆盖升级，首次安装时间保持；演示会话、29 条任务及冷启动保留，版本页正确；真实网页登录回调通过。
- 兼容签名四角色各 6 组配置/模板/团队页面、入口权限、工作区选择、返回及退出检查通过，共 24 组配对 PNG/XML。临时账号及工作区已清理，客户团队未修改。
- 8079 正式签名实际加载两类故障 AOT：固定错误类别到达原生诊断；移除、黑名单、拒绝重复应用和基础工作台恢复通过；测试敏感标记未进入对应进程日志。
- 两签名 APK 的直接 DEX Log/printStackTrace 调用检查归零；不据此声称 native 库、反射或系统崩溃输出已全面审计。
- 本次使用 AMD 显卡后端完成四角色运行，绕开了此前软件图形后端反复崩溃的测试阻碍；未证明所有环境长期稳定。

具体证据位于 `acceptance/privacy74-batch`、`upgrade75-batch`、`upgrade77-batch`、`roles78-batch`、`ota79-batch`。历史 8078 的原生 SIGSEGV 回退证据保留在 `native68-batch`。

## 后续待验收或专项工作

1. 实体手机/卡片的 NFC、相机、实物扫码和触觉，以及双真机协作；按实际设备结果补兼容性修复。
2. 其余二级页的完整中英文/小屏/大字原生检查、表单进入及返回、即时撤权、App→外部邮箱→App 找回密码往返。
3. 8079 的原生 SIGSEGV/ANR 回退专项、其他 Android API 与 ARM 真机，及 native 库/其他日志通道审计。8078 历史证据不能替代这些检查。
4. 外部用户试用反馈、第二主机完整恢复与生产切换、签名及解密密钥独立异地托管。
5. 新验收包升级为官网正式发布、以及基于 8079 的新 OTA 内容发布，仍须各自执行发布及下载/运行验证；本轮不把本地交付记作已上架。

这些条目保留在交付台账。当前阶段不再继续扩展开发或无限细节打磨。
