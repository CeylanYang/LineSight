## 云端更新范围

`flutter_patcher` 已用于兼容 Dart AOT 代码更新：后台下载，下次冷启动生效，Ed25519 验签、SHA-256、轨道/基础版本/ABI绑定及失败回退沿用原实现。

新增签名公共配置 `GET /api/v1/app-config/`：文档文字和检查标准、已支持的功能入口开关、报告团队落款、特供标题、文档原图及印章可云端下发。图片限 API 同源 `/content/<sha256>.png`，核验大小及哈希；配置过期/篡改/降级会被拒绝，断网保留有效缓存或内置版本。服务端无公开写配置入口。

本次新增字体、模板素材和打开官网的插件，必须先安装 8082 基础包。新的原生插件、权限、Flutter 引擎、未预留的内置素材依然需要新基础 APK；不能用配置增加任意原生能力。操作人员可更新 JSON 中已有组件支持的内容。发布或回滚配置均使用更高 revision。

## 运维操作

1. 修改 `deploy/runtime/app-config.json` 及 `assets/templates` 中的公共素材；不要加入任何凭据。
2. 使用已有私钥执行 `python tool/publish_runtime_content.py --revision N` 生成签名预览；递增 N，先核对内容。
3. 加 `--publish --evidence <receipt.json>` 发布。脚本先上传哈希素材，再原子替换配置，备份旧配置和相关路由；失败恢复。默认有效期180天，可在1至365天内指定。
4. Dart 更新使用 `tool/ota_release.py base/pack/upload`，显式传入 `--base 8082` 和轨道。`pack` 会拒绝原生、资源、权限、引擎漂移。回退使用更高 sequence 的 rollback。
5. 官网使用 `tool/publish_portal_downloads.py` 以及当前线上 index/app.js 哈希收据进行并发变更检查。正式版和预览版分别保留已有签名覆盖升级。
