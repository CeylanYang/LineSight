# 特供版交付说明 · 1.1.59+8083

工作区：`D:\ENT207\LineSight-special-edition`（`feature/special-edition`）。

## 使用

在“我的”设置中开启“特供版”。关闭时恢复大字版；开关默认关闭。两种模式使用同一个 Android 应用、登录态、团队权限和业务数据。

## 本次实现

- 保留 checkcheck 首页，补齐云端登录后的真实业务入口：在线质检、扫码、生产任务、异常处理、记录、质量报告、打印配置、检查模板。
- 生产、质检、配置、个人及使用共享页面容器的详情页复用 checkcheck 横幅、金币、礼物、会员、短剧封面、邀请、积分商城和广告素材。
- 福利入口优先展示；搜索、筛选、创建任务、报告等真实业务按钮保持可用。相机取景不插入广告区块。
- 特供版点击和页面进入/返回显示象征性进度圈：1% → 3%（180ms）→ 15%（430ms）→ 99%（540ms）→ 100%（580ms），620ms 关闭。不控制网络请求和业务结果，不进行预加载。
- 关闭特供版即取消进度圈。滚动手势不触发点击等待；连续点击不会延长当前进度周期。
- 活动积分支持每日领取去重、兑换余额检查及本机持久化明细；邀请按钮复制官网地址，不开放注册。
- 修复本地第五标签页关闭特供版时的索引映射；共享页使用稳定标识，页面模式切换不更改云端身份。
- 首页在不足 393 逻辑像素时整体等比适配；已覆盖 320/390 宽度的云端业务标签页交互检查。
