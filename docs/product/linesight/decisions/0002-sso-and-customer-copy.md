# 单点登录、演示账号与客户界面

2026-10-23，用户追加并确认：

1. 默认 API 端点内置于 App，不让客户填写服务地址。
2. 初始账号和密码预设在 App，用户明确选择 **共享演示账号，仅访问独立演示团队**。这不授权把正式管理员口令编入 App。
3. 单点登录使用现成开源项目，优先采用 Keycloak，通过标准 OIDC 接入 Android 和后端。需要实际部署、初始化和登录验证，不能把本机用户名密码登录改名为 SSO。
4. 客户页面不得出现严谨性声明、元叙事和防御性叙事。开发、测试和验收说明留在交付文档。必要的字段标签、操作提示、人工质检入口和实际错误恢复继续保留。

新增固定 ID：

- **SSO-01**：内置默认服务端点与共享演示账号入口；演示会话不得访问正式团队或创建正式业务工作区。账号密码由实际服务初始化结果决定，不能只填前端占位值。
- **SSO-02**：使用开源 Keycloak 提供单点登录；Android 使用标准授权流程，API 校验签名、issuer、audience、有效期，持久会话及登出按统一认证服务处理。
- **SSO-03**：初始化并验证演示 realm/client/user/密码和隔离团队；部署配置与恢复步骤留存，不在日志中输出正式密钥；实测跨会话登录、过期、登出及权限。
- **UI-12**：全界面客户文案审阅；清除开发叙事、评审话术及不必要的防御性声明，保留直接可执行的业务提示，中英文同步。

本次追加明确允许共享演示账号在 App 中预置，优先于原计划 REL-01 对“演示固定凭证”的一般限制；正式身份、管理员和基础设施凭证仍不内置。
