# 统一云端身份与 App 内登录页

2026-10-23，用户进一步明确，覆盖既有双账户入口设计：

- 普通用户与团队用户的认证、登录均由云端管理。
- 不再区分“普通用户登录”和“团队登录”两个客户入口。
- 登录作为 App 内的二级页面；团队是同一云端身份下的工作区及成员角色。
- 先完成上述认证基础，再继续二级页面及功能开发，优先按产品计划正文实施。

实施约束：保留四栏主导航，访客视图不读取受保护的本机数据。历史本机记录按 SEC-01 保持受保护的兼容导入，不能用新云端登录静默解锁旧本机记录。新业务账户及权限统一在云端，不再新增常规本机账户入口。

验收补充 **SSO-04**：同一账号完成登录、个人资料和团队切换；登录页面为二级路由；普通用户与团队用户不再出现两个独立登录入口；退出/过期后不泄露其他账号或团队缓存，草稿按身份隔离。
